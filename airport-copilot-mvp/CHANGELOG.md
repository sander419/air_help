# Changelog

## v1.4.0 (2026-08-18) — Полный газ! Production Ready

### 🚀 Новое в версии 1.4.0

#### Адаптация под российский рынок
- **Русский язык по умолчанию** во всех интерфейсах
- **Российские аэропорты**: SVO (Шереметьево), DME (Домодедово), VKO (Внуково), LED (Пулково)
- **Российские авиакомпании**: SU (Аэрофлот), DP (Победа), S7 (Сибирь), UT (ЮТэйр)
- **Приказы Минтранса РФ** и Росавиации в базе правил
- **Фразы на русском и английском** для общения с персоналом
- **Учет специфики внутренних рейсов** по России

#### Расширенная база проблемных сценариев
- Все **15 обязательных сценариев** из спецификации
- Детальные шаги для каждого сценария
- Фразы для общения с сотрудниками на двух языках

#### Улучшенная архитектура
- **4366 строк кода** ядра системы
- **17 файлов** исходного кода
- **6 custom hooks** для реактивной логики
- **3 движка**: RuleEngine, NotificationEngine, OfflinePackageManager
- **AppContext** для глобального состояния

#### Технические улучшения
- Детерминированный расчёт Wh = mAh × V / 1000 (не LLM!)
- Приоритет источников: 8 уровней от госорганов до вторичных
- Офлайн-режим с датой последней синхронизации
- TTS (Text-to-Speech) для фраз сотруднику
- Clipboard API для копирования текста

### 🎯 Сценарии использования

1. **Первый полёт** — пошаговый навигатор по этапам
2. **Проблема с багажом** — 3 шага + фраза сотруднику
3. **Задержка рейса** — оценка риска пересадки
4. **Проверка power bank** — детерминированный расчёт Wh
5. **Потерянный паспорт** — контакты + фразы
6. **Не знаю английский** — переводчик с озвучкой

### 🔧 Технологический стек

- **React 18.3** — UI библиотека
- **Vite 5.4** — Сборщик
- **Context API + useReducer** — Управление состоянием
- **Custom Hooks** — Бизнес-логика
- **CSS-in-JS** — Стилизация
- **Speech Synthesis API** — Озвучка фраз
- **Clipboard API** — Копирование текста

### 📱 Accessibility (WCAG 2.1)

- ✅ Touch targets ≥48×48 px
- ✅ Высокий контраст (#0f172a фон, #f8fafc текст)
- ✅ Крупный шрифт (16-22px основной, 32px employee mode)
- ✅ Не только цвет для передачи информации
- ✅ Поддержка screen readers
- ✅ Режим одной руки

### 🌐 Offline-first

- Синхронизация при подключении
- Явное отображение даты последней синхронизации
- Fallback на моковые данные при отсутствии API
- Офлайн-пакеты для каждой поездки

### 📦 Развёртывание

```bash
# Установка зависимостей
npm install

# Dev сервер (порт 5173-5174)
npm run dev

# Production сборка
npm run build

# Preview production
npm run preview
```

Production билд готов в `/dist/` — можно деплоить на:
- GitHub Pages
- Netlify
- Vercel
- Любой статический хостинг
